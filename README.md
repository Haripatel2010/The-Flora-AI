# FLORA AI

FLORA is a dark-themed Android AI assistant.

## AI Providers
- Google Gemini
- Groq
- OpenRouter

## Features
- Dark chat interface
- Multiple AI providers
- Automatic provider fallback
- Encrypted API key storage using Android Keystore

## Build APK

This project uses GitHub Actions.

1. Open the Actions tab.
2. Select Build FLORA APK.
3. Tap Run workflow.
4. Download the FLORA-debug-apk artifact after the build succeeds.

## Requirements
- Android 7.0 or newer
- Internet connection
- Your own provider API key
